## args ['-h']
  exit code: 0
  | Usage of <BIN>:
  |   -host string
  |     	this host's own tailnet/LAN IPv4 address, for relay-mode device legs' SDP (§9.3, §9.9); empty = the local address of the SIP socket that talks to that device
  |   -house-calls
  |     	enable the house-call bridge (house_open / house_close, M7 3b-Go); off, both verbs answer not_supported and nothing is created
  |   -ipc-allow-from string
  |     	comma-separated IPs/CIDRs allowed to connect to the TCP IPC (the HA host)
  |   -ipc-allow-non-loopback
  |     	allow -listen on a non-loopback address (also needs -ipc-allow-from)
  |   -ipc-token-file string
  |     	file holding the TCP IPC token (a docker secret); overrides PORTICO_IPC_TOKEN
  |   -listen string
  |     	standalone/container mode (DEV-518 W8): serve the IPC over TCP at host:port instead of -socket; needs a token (PORTICO_IPC_TOKEN or -ipc-token-file); loopback unless -ipc-allow-non-loopback AND -ipc-allow-from
  |   -secrets-env string
  |     	read the SIP password/user/realm and the IPC token from this KEY=VALUE .env file (GATE_SIP_PASSWORD, GATE_SIP_USER, GATE_SIP_REALM, GATE_SIP_PEER_TOKEN; every other key is ignored); explicit PORTICO_* variables and -ipc-token-file override it; read once at start
  |   -sip-from-env
  |     	configure and start one gate_sip_server from PORTICO_SIP_* variables at start-up; the hub's later configure/deconfigure of it only adopt/detach
  |   -socket string
  |     	IPC unix socket path (§9.4)
